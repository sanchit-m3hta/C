----------------------2.1 Process Introduction----------------------
A process in an operating system is essentially a program in execution. you execute programs.
- program in execution is called a process i.e a running program is a process.
- every function will have a stack associated with it.
- the stack contains temporary data when invoking functions like function paramters, return addresses, local variables (activation record).
-The size of stack memory is determined at compile time, but it is allocated at runtime when functions are called,
    whereas heap memory is allocated dynamically at runtime.
- program counter will not have a history of addresses

Can more than one process be associated with a program? Yes
the text portion the memory will be the same between twp processes,
but data, heap, and stack may not be the same between two processes.
the stack and heap are dynamic, meaning they can grown and shrink


Stack
- The stack does not always decrease.
- It grows when a function is called (new stack frame added).
- It shrinks when a function returns (stack frame removed).
- So it fluctuates: grows and shrinks dynamically as functions are called and return.

Heap
- The heap can grow when memory is allocated dynamically (malloc/new).
- It can shrink when memory is freed (free/delete).
- Its growth/shrinkage depends entirely on your program’s dynamic memory usage.

Q. What is removed from P-core to make an E-core
Big piplines and buffers
    - P cores have very wide out of order instruction pipelines and massive reorder buffers.
       Higher pipelines -> higher througput -> higher performance
    - E cores have narrower pipelines and smaller reorder buffersm which consume less silicon and power.
Cache heirarchy simplified
    - P cores have higher larger private L2 caches and share larger slices of L3
    - E cores ues smaller L2 caches and sometimes skip compex prefetching or aggresive L3 connectivity.
clock speed limits
    - P core are designed for higher frequencies (5+Ghz turbo), while E-cores are optimized for 2-3Ghz
